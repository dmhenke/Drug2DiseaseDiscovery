Drug reversal lookup

Exploratory. SLE vs healthy signatures from the lupus UCE test run, matched against LINCS L1000 compound signatures in cancer cell lines.

  • The pipeline has not tested any chemicals. It compares SLE with healthy cells. This page sends those differences to an external drug database (L1000CDS2) and lists the compounds whose signatures move the same genes the opposite way. Known
  • Only the two monocyte signatures beat random gene sets (classical and non-classical monocytes), so only those are shown by default. The NK and CD4 T results score no better than random genes and are hidden unless you tick the box below. Known
  • The hits mostly reflect the interferon genes. Nearly every compound reverses the same core set (IFI44L, IFIT1, ISG15, MX1…). Many top hits are general cytotoxic agents (a PLK1 inhibitor, microtubule poisons, a proteasome inhibitor, HSP90 inhibitors), which tend to damp many pathways at once. Inferred
  • Pre-set check: “at least one JAK inhibitor among named hits for classical monocytes.” Technically met: TG101348 (fedratinib, a JAK2 inhibitor; identity from memory) ranks 31st. But it also appears for NK and CD4 T, which failed calibration. That suggests it is a frequent hitter in this database rather than a specific match. Inferred
  • Not a treatment ranking. The drug signatures come from cancer cell lines over 3–24 h, not immune cells. A high score means overlapping genes, not a predicted benefit.

Calibration: does each signature beat random genes?

Each cell type's signature was queried once, together with 5 random signatures of the same size drawn from its non-significant genes. A signature passes when both its best score and its median top-50 score exceed all 5 random sets. With only 5 random sets, passing corresponds to p ≈ 1/6 at best, so this is a coarse screen.

The reversed-gene filter shows which compounds push a given gene back toward healthy. For example, IFI27 is up in SLE and is pushed down in 20 of the 50 classical-monocyte matches.

Method

  • Signatures: genes at padj < 0.05 (pseudobulk DESeq2, 20 SLE vs 20 healthy, Perez 2022 cohort 4) in each cell type. Ribosomal and mitochondrial genes were removed because their signal is unexplained (see the run report). CD8 T (2 genes), B (3) and cDC (0) were too small to query.
  • Database: L1000CDS2 (Duan et al. 2016, npj Syst Biol Appl), reverse mode, gene-set search, latest database version, top 50 signatures per query. Queried 2026-11-01. Only gene symbols were sent to the server.
  • Unnamed compounds (listed by BRD ID only) are Broad screening compounds without a public name in L1000.
  • To rerun: python scripts/l1000_reversal.py studies/lupus_test/results <out dir>. The server's database or ranking can change, so a rerun may differ.

What would make this a real drug screen

Use perturbations of immune cells rather than cancer lines: OP3 (146 compounds in PBMCs, GSE279945), the Parse cytokine screen, or Kang 2018 (IFN-β on lupus PBMCs). Run each through the pipeline's own DE with a paired design (~ donor + treatment). Then score how far each compound moves the SLE signature toward healthy, in the same cell type. None of that exists yet.
