What was tested

The pipeline embeds cells with a pretrained foundation model, Universal Cell Embeddings (UCE), and clusters them on that embedding. It then runs pseudobulk DESeq2 per cell type, SLE against healthy. This run asked two questions:

  1. Does the UCE step run on the workstation, and how fast?
  2. With UCE in place, does the pipeline still recover an answer key? Here that is the type I interferon signature in SLE monocytes, one of the most replicated findings in lupus.

UCE is used for projection only. The published weights are loaded and every cell gets one forward pass with gradients off. Nothing is trained or fine-tuned, and the model never sees disease status. Known, from UCE evaluate.py

DataPerez et al. 2022, Science 376:eabf1970 (PMID 35389781). CELLxGENE dataset c55dc602, 1.26M PBMCs.
SelectionFemale, European American, Processing_Cohort 4. 20 donors per group drawn at random (seed 1234), up to 500 cells each.
Why cohort 4 aloneCohort 1 has no SLE donors. Ancestry and sex are strongly tied to disease: Asian-ancestry cells are 82% SLE and male cells 88%. And 36 female European American donors were sequenced in more than one cohort, so pooling cohorts would count them twice. One cohort means one batch, with no batch term needed and no donor counted twice.
Cells and genes19,988 cells (9,994 per group) × 13,658 genes after QC. UCE used the 11,985 genes that have a protein embedding and dropped no cells.
EmbeddingUCE 33-layer (33l_8ep_1024t_1280.torch, md5 eed62d4f…), batch 8, seed 1234. Output is 1,280 dimensions.
Cell typesCELLxGENE cell_type labels (CELL_TYPE_COL). Louvain clusters (k = 30) on the UCE embedding are kept as a cross-check.
DEPseudobulk sums per donor × cell type. DESeq2 ~ condition (one batch). A cell type is tested when it has ≥10 cells per sample and ≥3 samples per group. Benjamini–Hochberg within each cell type, padj < 0.05.

  • The major lineages separate cleanly. B cells: 99.9% in cluster 9. NK: 98% in cluster 6. Non-classical monocytes: 96% in cluster 8. Classical monocytes: 99% in clusters 4 and 7. pDCs: all in cluster 10. Known
  • CD4 and CD8 T cells mix. Cluster 1 holds 2,690 CD4 and 728 CD8 cells, and only 52% of CD8 cells fall in the CD8 cluster (2). Naive CD4 and CD8 cells often sit together in embeddings, which would explain it. Guess, not checked with naive markers
  • Two splits are not yet explained: classical monocytes into clusters 4 and 7, and CD4 T into 1, 3 and 5. They could be subtypes, or they could be SLE vs healthy. That matters, because clusters that follow disease cannot serve as cell types for DE. The check (scripts/cluster_check.R) is written but not yet run.

Open finding: ribosomal genes down in SLE T and NK cells

In CD4 T cells, 35 of the 46 significant genes are ribosomal or mitochondrial, and all of them are down in SLE. FOS is down too. NK cells show 10 such genes. The same pattern appeared in the T/NK clusters of the PCA run, so it does not depend on the embedding.

Leading explanation: a shift in which cells are present. The label “CD4-positive, alpha-beta T cell” includes both naive and memory cells, and naive T cells carry more ribosomal transcripts. If SLE patients have fewer naive CD4 T cells, the SLE pseudobulk shows less ribosomal RNA without any gene changing within a cell. Inferred

Test: if this is right, SLE cells will be under-represented in the CCR7/SELL-high CD4 cluster. Alternative: differences in sample handling, such as time to processing affecting FOS. These would not separate along naive markers.

Until this is resolved, ribosomal and FOS hits in T/NK cells should not be reported as disease biology.

Recommendation

  1. Run scripts/cluster_check.R on this run's output. It answers two things: whether UCE clusters follow disease, and whether the ribosomal signal comes from a shift in cell types.
  2. Run option A in PCA mode with author labels. With CELL_TYPE_COL set, the DE uses the labels and the counts. The embedding affects only the cross-check clusters. As long as every cell is kept, as UCE did here, PCA mode gives the same DE in minutes instead of about 3 days. Inferred from code, not yet checked by running both
  3. Keep UCE for cross-study work: combining datasets whose cell types are annotated differently or not at all. That is the purpose of the pipeline. A 3-day UCE run on cohort 4 is worth doing only to benchmark UCE itself.

Not verified

  • That Perez 2022 is absent from UCE's training data. If it was included, the model has seen these cells, which would flatter any claim about how well UCE handles new data. The DE is unaffected. Unchecked
  • The cell count for option A, and R memory use at 1.26M cells.
  • That PCA and UCE modes give identical DE when labels are used. This follows from the code but has not been run.
  • A negative control: the same pipeline on healthy vs healthy donors, which should give about 0 DE genes. Not yet written.
  • The number of tests: adjustment is within each cell type only. The six cell types shown ran 16,612 gene tests (B cells not counted), with no correction across cell types.
